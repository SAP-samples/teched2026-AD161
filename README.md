# AD161 - Build and operate agentic solutions with Joule Studio

## Description

This repository contains the material for the SAP TechEd 2026 session called AD161 - Build and operate agentic solutions with Joule Studio  

## Overview

This session introduces attendees to SAP Joule Studio. In this session attendees would build, deploy, operate and interact with agentic solutions using Joule Studio and Joule Work. 


| Exercise | Topic | Estimated Time |
| :---         | :---         | :--- |
| Exercise 1 | Invoke Agents by interacting with Joule Work | 15 mins |
| Exercise 2 | Monitor Solutions and Agents with Joule Studio | 15 mins |
| Exercise 3 | Build, Test, Deploy and Operate an agentic solution with Joule Studio | 60 mins  | 
| Exercise 4 | (Optional) Push your agentic solutions to git and promote to production | 20 mins |   

## Requirements

- Joule Work connected to a S/4 HANA Public Cloud
- Joule Studio
- Browser on the laptop (Chrome)
- Exercise 4 requires you to have your own git repository

> All required tools and services have been pre-configured. You need a browser to get through this session
